# Regola di Progetto: Sincronizzazione Continua Knowledge Base (AnthropicUsage)

La cartella ufficiale delle Knowledge Base di progetto è `D:\AI-KnowledgeBase\AnthropicUsage\` (su Linux: `/run/media/giuspo/DATA/AI-KnowledgeBase/AnthropicUsage/`) e contiene due file Markdown distinti:

1. **KB Baseline Single-Provider (`v1.x` — Claude Code)**:
   - `D:\AI-KnowledgeBase\AnthropicUsage\Claude_Code_Widget_KB.md`
2. **KB Evoluzione Multi-Provider (`v2.0+` — Claude Code + Google Antigravity / Google AI Pro)**:
   - `D:\AI-KnowledgeBase\AnthropicUsage\Antigravity_MultiProvider_v2_KB.md`

## Obblighi Operativi per Ogni Sessione

- **All'inizio di ogni sessione**: leggere `Antigravity_MultiProvider_v2_KB.md` (e `Claude_Code_Widget_KB.md` per i dettagli storici della baseline `v1.x`) per allinearsi su architettura, decisioni e stato della roadmap.
- **Aggiornamento Continuo Obbligatorio**: qualsiasi decisione architetturale, scelta UX/UI, modifica allo stack, aggiornamento di endpoint, flusso OAuth, schema dati o avanzamento della roadmap relativo alla modifica **Multi-Provider / Google Antigravity** DEVE essere immediatamente riflesso e mantenuto costantemente aggiornato nel singolo file `D:\AI-KnowledgeBase\AnthropicUsage\Antigravity_MultiProvider_v2_KB.md` senza attendere richiesta esplicita dell'utente.
